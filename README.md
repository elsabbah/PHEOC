# PHEOC-OMS

تطبيق ASP.NET Core MVC عربي RTL لإدارة عمليات طوارئ الصحة العامة، مرتبط بـSQL Server 2016، مع موصل قراءة فعلي لـEgyptEBS.

## التشغيل المحلي

للتشغيل بالنقر المزدوج، افتح `Start-PHEOC.cmd` من جذر المشروع واترك نافذة التشغيل مفتوحة. يعرض السكربت تقدم البناء ثم عنوان التطبيق ورسالة بدء الاستماع. إذا كانت نسخة سليمة تعمل بالفعل يعرض رابطها دون تشغيل نسخة ثانية. لإيقاف التطبيق اضغط Ctrl+C في نافذة تشغيله؛ ولتطبيق تعديلات جديدة أوقف النسخة ثم أعد التشغيل.

من PowerShell داخل جذر المشروع:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/Start-Development.ps1
```

افتح `http://localhost:5268`. حساب المدير المحلي `pheoc.admin`. لعرض كلمة المرور المولّدة **محلياً على جهازك فقط**:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/Show-DevelopmentLogin.ps1
```

بيانات الاتصال وكلمات المرور ومفتاح API محفوظة في .NET User Secrets خارج المشروع. لا توجد كلمة مرور افتراضية ثابتة في المصدر. سكربت العرض لا يعرض بيانات SQL أو مفاتيح التكامل؛ لا تلتقط مخرجاته في سجل مشترك.

## ما يمكن استخدامه

- تسجيل الدخول والصلاحيات الصريحة والنطاق حسب المحافظة، وإدارة إنشاء المستخدمين.
- لوحة قيادة وWall Display وسجل أحداث مع البحث والترشيح وترقيم الصفحات.
- تقييم المخاطر بمصفوفات معتمدة ذات إصدارات، وقرار تفعيل، وتعيينات IMS، ومهام وقرارات تصحيحية محفوظة.
- أفراد وفرق وأوامر نشر ووصول وعودة، مع منع تكليف العضو مرتين بالتزامن.
- مستودعات وأصناف ودفعات وحركات وتحويل مخزون، وطلبات إمداد باعتماد مستقل ومركبات وتكليفاتها.
- تقارير ميدانية، ومتابعة مخالطين برموز، وعينات وسلسلة حيازة ونتائج.
- رسائل ومرفقات مفوضة، وتنبيهات SLA بإصدارات وتصعيد، وSignalR.
- تقارير موقفية بلقطات بيانات، واعتماد مستقل وتصدير Excel وWord وطباعة/حفظ PDF من المتصفح.
- توثيق وحساب 7-1-7 مع أدلة ومبررات عدم الانطباق والاستبعاد، بصورة مستقلة عن SLA.
- إغلاق بشروط وسياسات ذات إصدارات، وإغلاق استثنائي بصلاحية خاصة، ثم AAR وخطة تحسين.
- خريطة Leaflet وحدود مصر محلياً؛ وأساس PWA مع مسودات ميدانية مشفرة مؤقتة ومزامنة بمعرف طلب ثابت.
- استقبال يدوي من EgyptEBS واستقبال تلقائي اختياري من نقطة تفعيل، إضافة إلى Push API موثق في `/openapi.json`.

## التهيئة في بيئة أخرى

```powershell
dotnet restore PHEOC.OMS.sln
dotnet build PHEOC.OMS.sln
powershell -ExecutionPolicy Bypass -File scripts/Initialize-Development.ps1
```

التهيئة تطلب كلمة مرور SQL بشكل آمن وتستهدف PHEOC_OMS فقط. لا تُطبق migrations عند بدء التطبيق العادي. صلاحيات قارئ EgyptEBS إجراء منفصل موثق في [دليل النشر](docs/Deployment.md).

## التحقق والوثائق

```powershell
powershell -ExecutionPolicy Bypass -File scripts/Test-Application.ps1
# يتطلب التطبيق قيد التشغيل وChrome واستخدام المتصفح يضيف سجلات تدريب موسومة:
powershell -ExecutionPolicy Bypass -File scripts/Test-Application.ps1 -Browser
```

اختبارات SQL التشغيلية تُرجع معاملاتها ولا تترك بياناتها. اختبارات المتصفح تحفظ أحداثاً تدريبية واضحة مستبعدة من المؤشرات، وتترك سجلاتها للمراجعة. لا تُحذف بيانات أو سجلات تدقيق تلقائياً.
