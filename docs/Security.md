# الأمن والتحقق

## ضوابط منفذة

- ASP.NET Core Identity، كلمات مرور لا تقل عن 12 حرفاً مع تنوع، قفل بعد خمس محاولات، جلسة 30 دقيقة، cookies HttpOnly وSameSite، وSecure في الإنتاج.
- سياسات Permissions تطبق على الخادم داخل الخدمات، ونطاق محافظة على استعلامات الأحداث والموارد. إخفاء التنقل ليس حاجز التفويض.
- Anti-forgery لنماذج cookies؛ API تكامل مستقل بمفتاح ومحدد معدل طلبات وحجم 64 KB. حدود لمحاولات الدخول.
- CSP وX-Frame-Options وnosniff وعدم تخزين الصفحات المصادق عليها في cache، وترميز Razor للمخرجات.
- User Secrets/Environment Variables، وحساب SQL محدود، وقراءة فقط لـEgyptEBS، ومهاجرات صريحة منفصلة عن بدء التطبيق.
- RowVersion ومعاملات للعمليات الحساسة، وأقفال تطبيق SQL لهوية رسائل Inbox مع قيود فريدة واختبار طلبات متزامنة.
- سجل تدقيق يحفظ الفاعل والإجراء ونوع الكيان ومعرفه دون كلمات مرور أو نسخ المحتوى الصحي. منع تعديل السجلات الدفترية في DbContext وصلاحيات SQL.
- المرفقات خارج wwwroot؛ 5 MB؛ قائمة PDF/PNG/JPEG/TXT والتحقق من التوقيع أو UTF-8؛ اسم تخزين عشوائي وSHA256 وتنزيل مفوض كملف مرفق.
- تفاصيل المخالطين برموز تشغيلية؛ أذونات صحية منفصلة؛ بيانات المبلغين وأرقام الاتصال في EBS ليست ضمن عقد القراءة.
- مسودات الميدان اختيارية ومشفرة AES-GCM، مفتاحها في جلسة علامة التبويب، 24 ساعة و10 مسودات، ومعرف طلب لمنع تكرار المزامنة. لا يخزن Service Worker صفحات أو API مصادقاً عليها.

## أدلة وحدود

نجحت اختبارات دخول ومنع الوصول غير المصرح، وCSRF، والتزامن، ومنع تجاوز المخزون وتكرار التكليف، وشروط الاعتماد، وقراءة مصدر EBS بحساب لا يملك كتابة. توجد اختبارات متصفح وصور للحاسب والهاتف. فحص NuGet بعد تحديث Pkcs إلى 10.0.13 لم يبلغ عن حزم ضعيفة معروفة في المصدر المستخدم؛ npm audit لم يبلغ عن ثغرات في حزم الواجهة.

هذا ليس تقرير اختبار اختراق شامل. لم تُختبر مزودات الإشعارات الخارجية، ولم تُعتمد سياسات الخصوصية والاحتفاظ وطنياً، ولم يُنفذ فحص برمجيات خبيثة للمرفقات أو اختبار حمل إنتاجي أو استعادة احتياطية. فحص نوع الملف ليس مضاد فيروسات. لا يوجد تشفير حقول صحي مخصص أو TDE مثبت بالمشاهدة؛ حماية Inbox وDPAPI لا تعني تشفير قاعدة البيانات كلها.

المسودة المشفرة تعتمد على بقاء جلسة علامة التبويب؛ بعد فقد مفتاحها لا يمكن استعادة محتواها. لا تُحفظ بيانات شخصية أو صحية تفصيلية في المسودات. يجب مسحها على الأجهزة المشتركة. مزامنة المسودة تتطلب جلسة صالحة وصلاحية مستمرة وتكليفاً مفتوحاً، ولا تمحو المسودة عند رفض الخادم.

مراجعة ما قبل الإنتاج تشمل MFA وسياسة إنهاء الجلسات وتغيير/إلغاء الصلاحيات وإدارة دورة حياة الحسابات، وتحديث Runtime ومحرك SQL، وسياسات تشفير الاتصال والتخزين، والاختبارات الأمنية الكاملة.

تعطيل الحساب وإعادة تعيين كلمة المرور منفذان بصلاحية إدارية، مع تغيير SecurityStamp وإعادة التحقق من الجلسات خلال دقيقة. تعديل مصفوفة صلاحيات مستخدم قائم ونطاقه من الواجهة ما زال يحتاج استكمالاً؛ لا تُفترض هذه الوظيفة من وجود زر إنشاء مستخدم.
